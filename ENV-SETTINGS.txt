Add these in Netlify: Site configuration -> Environment variables -> Add a variable (one by one).
Name                  Value
DATABASE_URL          Neon "direct" connection string (starts with postgres://) - NOT the pooled one
ADMIN_EMAILS          your own email (more allowed, separated by commas)
GMAIL_USER            the Gmail address that sends your emails, e.g. trexapp@gmail.com
GMAIL_APP_PASSWORD    the 16-character Google "App password" for that Gmail
PAYSTACK_SECRET_KEY   Paystack TEST secret key (sk_test_...) for now
PAYSTACK_BANK         test-bank   (use wema-bank only when Paystack is live)
Paystack dashboard -> Settings -> API Keys & Webhooks -> Test Webhook URL:
https://YOURSITE.netlify.app/api/paystack/webhook
After deploying open  https://YOURSITE.netlify.app/api/health
  it must show "database":"postgres", "auth":"better-auth", "email":"gmail"
Then sign in with your admin email and open  https://YOURSITE.netlify.app/api/authcheck  -> every line "ok":true
